# StudentHub Portal



### Objectives

* Provide a centralized student portal
* Enable user registration and login
* Allow students to view academic and campus information
* Display upcoming events and announcements



### User Roles

* Register and Login
* Edit profile
* View dashboard
* View events
* Check announcements
* Give feedback



### Functional requirements

* Home page
* About page
* Student registration
* Student Login
* Dashboard
* Student profile
* Contact page
* FAQ page
* Admin page



### Non-Functional Requirements

* Semantic HTML5 structure
* Easy navigation
* Secure authentication
* Accessibility
* Responsive design



### Technologies

* HTML5
* CSS
* JavaScript
