# StudentHub-Portal

A student portal website developed as part of the **Web Development Frameworks practical work**.

## 📚 About

This repository contains the development of the **StudentHub Portal**, a web-based platform designed to bring useful student-related information and services together in one place.

The project is developed progressively through practicals throughout the course. Each practical builds upon the previous work and may include planning, documentation, wireframes, web pages, styling, scripting, and other components of the portal.

## 🛠️ Technologies

* HTML
* CSS
* JavaScript

## 📁 Repository Structure

The project is organized into separate folders for each practical. These folders contain the work, documentation, designs, and source files developed during the corresponding stage of the project.

## 🎯 Purpose

The project aims to provide practical experience in:

* Web page design and development
* Website structure and navigation
* UI planning and wireframing
* HTML, CSS, and JavaScript
* Adding interactivity and functionality to web pages
* Organizing and developing a web project incrementally
